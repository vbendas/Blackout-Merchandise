# Merch Coins: Two-Tier System Documentation

## Executive Summary

Merch From uses a **two-tier coin system** to create a sustainable, scalable promotional ecosystem:

1. **Platform Merch Coins** — Universal currency issued by Merch From (works anywhere)
2. **Artist Merch Coins** — Branded currency issued by artists (works only on that artist's store)

This separation ensures clean economics, clear accounting, and powerful branding opportunities for both platform and artists.

---

## System Overview

### **1. Platform Merch Coins (Universal Currency)**

**Label:** Simply "**Merch Coin**" (no name prefix)

**Issued By:** Merch From platform

**Sources:**
- Crowdfunding backer rewards (€25-€2,500 tiers)
- Platform promotions (new customer welcome bonus, referrals, seasonal campaigns)
- Partnership rewards
- Customer service recovery (e.g., issue resolution)

**Usable For:**
- ✅ Purchase from **any artist's merch store**
- ✅ **Bulk screen printing orders** (wholesale direct with platform)
- ✅ Works across entire platform ecosystem

**Economic Model:**
- **Deducted from:** Platform's base margin (€15 per product)
- **Platform absorbs cost:** Yes
- **Artist impact:** None — artist still gets full margin

**Never Expire:** Lifetime value

**Visual Identity:**
- Simple, clean icon (neutral design)
- Silver/grey color scheme
- No artist branding
- Universal symbol

---

### **2. Artist Merch Coins (Artist-Branded Currency)**

**Label:** "**[Artist Name]'s Merch Coin**"  
(e.g., *Sailor Jerry's Merch Coin*, *The Echoes' Merch Coin*)

**Issued By:** Individual artists

**Sources:**
- Free monthly allocation based on subscription tier:
  - Free: 100 coins/month
  - Pro: 500 coins/month
  - Studio: 1,000 coins/month
- Artist giveaways and contests (Twitter, Instagram, TikTok)
- Loyalty rewards (e.g., "10th purchase = 25 coins")
- Review incentives (e.g., "Leave review with photo = 15 coins")
- Performance bonuses for sales milestones

**Usable For:**
- ✅ Purchase from **only that specific artist's merch store**
- ❌ Cannot be used on other artists' stores
- ❌ Cannot be used for bulk wholesale orders

**Economic Model:**
- **Deducted from:** Artist's profit margin only
- **Artist absorbs cost:** Yes
- **Platform impact:** None — platform still gets base cost

**Never Expire:** Lifetime value

**Visual Identity:**
- Same icon shape as Platform coins, but artist-branded
- Artist's brand color
- Artist name in custom font
- Small artist avatar/logo next to amount

## Economic Integrity

### **Platform Coins Math**

**Example: Customer uses 10 Platform Merch Coins on €30 order**

```
Product Price: €30
Platform Base Cost: €15 (production + fulfillment)
Platform Base Margin: €15
Artist Margin: €0 (example: artist chose base pricing)

Customer uses 10 Platform Coins:
├─ Customer Pays: €20 (€30 - €10)
├─ Platform Gets: €5 (€15 base margin - €10 coin discount)
└─ Artist Gets: €0 (unchanged)

Result:
✅ Platform: €5 margin (reduced from €15)
✅ Customer: €10 saved
✅ Artist: €0 margin (unchanged)
```

**Key Point:** Platform absorbs the cost from their base margin. Artist is unaffected.

---

### **Artist Coins Math**

**Example: Customer uses 10 Sailor Jerry Merch Coins on €30 order**

```
Product Price: €30
Platform Base Cost: €15
Artist Margin: €10 (artist added markup)

Customer uses 10 Sailor Jerry Coins:
├─ Customer Pays: €20 (€30 - €10)
├─ Platform Gets: €15 (unchanged)
└─ Artist Gets: €0 (€10 margin - €10 coin discount)

Result:
✅ Platform: €15 base cost (unchanged)
✅ Customer: €10 saved
✅ Artist: €0 margin (reduced from €10)
```

**Key Point:** Artist absorbs the cost from their profit margin. Platform is unaffected.

---

### **Combining Both Coins**

**Example: Customer uses 5 Platform + 10 Artist Coins on €30 order**

```
Product Price: €30
Platform Base Cost: €15
Artist Margin: €10

Customer uses 5 Platform Coins + 10 Sailor Jerry Coins:
├─ Customer Pays: €15 (€30 - €15 total discount)
├─ Platform Gets: €10 (€15 base margin - €5 Platform coins)

Result:
✅ Platform: €10 margin (reduced from €15)
✅ Customer: €15 saved
✅ Artist: €0 margin (reduced from €10)
```

**Key Point:** Each party absorbs their own coin costs. Clean separation.

## Why This System Works

### **1. Economic Clarity**
- Platform controls their promotions (Platform coins)
- Artists control their promotions (Artist coins)
- No confusion about who pays for what
- Clean P&L: Each party's margin tracked separately

### **2. Branding Power**
- **Artist coins = brand loyalty**
  - "Collect Sailor Jerry's Merch Coins!"
  - Fans identify with artist-branded currency
  - Creates collectible psychology
  - Emotional connection to artist
  
- **Platform coins = universal utility**
  - Works everywhere = high perceived value
  - Crowdfunding backers get premium currency
  - No restrictions = ultimate flexibility

### **3. Marketing Flexibility**
- **Artists:** Run social campaigns without platform involvement
- **Platform:** Run acquisition campaigns without artist coordination
- Both parties can optimize independently
- No conflict or coordination overhead

### **4. Customer Simplicity**
- Visual distinction (branding) makes it obvious which coins work where
- Wallet shows both types clearly
- Checkout shows which coins are usable on current order
- Error messages are clear: "Artist coins only work on that artist's store"

### **5. Scalability**
- Artists can issue unlimited branded coins (their margin, their choice)
- Platform can issue unlimited universal coins (our margin, our choice)
- No central coordination needed
- System scales to thousands of artists automatically

### **6. Trust Signal**
- **Neither coin type expires** = genuine generosity
- Customers never lose value
- Long-term engagement (use coins years later)
- Word of mouth: "I still have coins from 2025!"

## Technical Implementation

### **Database Schema**

**Note:** Schema is future-proofed for potential internal trading (Year 2+), but launch implementation is NON-TRADABLE only. See PRD Section 2.8 "Launch Strategy: Non-Tradable with Future Upgrade Path" for full details.

```sql
CREATE TABLE merch_coin_balances (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES user_profiles(id) ON DELETE CASCADE,
  coin_type TEXT CHECK (coin_type IN ('platform', 'artist')),
  issuer_id UUID, -- NULL for platform coins, artist_id for artist coins
  issuer_name TEXT, -- NULL for platform, "Sailor Jerry" for artist
  balance INTEGER DEFAULT 0,
  earned_lifetime INTEGER DEFAULT 0,
  spent_lifetime INTEGER DEFAULT 0,
  last_updated TIMESTAMP DEFAULT NOW()
  -- Future: Add 'tradable BOOLEAN DEFAULT false' if trading enabled
);

CREATE INDEX idx_coin_balances_user ON merch_coin_balances(user_id);
CREATE INDEX idx_coin_balances_issuer ON merch_coin_balances(issuer_id);

CREATE TABLE merch_coin_transactions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL,
  coin_type TEXT CHECK (coin_type IN ('platform', 'artist')),
  issuer_id UUID, -- NULL for platform, artist_id for artist coins
  amount INTEGER NOT NULL, -- Positive = earn, Negative = spend
  transaction_type TEXT NOT NULL, -- 'allocation', 'giveaway', 'redemption', 'bonus', etc.
  reference_id UUID, -- Links to orders, campaigns, etc.
  description TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_coin_tx_user ON merch_coin_transactions(user_id);
CREATE INDEX idx_coin_tx_type ON merch_coin_transactions(transaction_type);
```

### **Checkout Validation Logic**

```typescript
interface CoinRedemption {
  coinType: 'platform' | 'artist';
  issuerId: string | null; // null for platform
  amount: number;
}

export function validateCoinUsage(
  order: Order,
  redemptions: CoinRedemption[]
): ValidationResult {
  
  // Separate platform vs artist coins
  const platformCoins = redemptions.filter(r => r.coinType === 'platform');
  const artistCoins = redemptions.filter(r => r.coinType === 'artist');
  
  // Rule 1: Artist coins must match the order's artist
  for (const coin of artistCoins) {
    if (coin.issuerId !== order.artistId) {
      return {
        valid: false,
        error: `${coin.issuerName}'s Merch Coins can only be used on their store.`
      };
    }
  }
  
  // Rule 2: Artist coins cannot be used for bulk orders
  if (order.orderType === 'bulk') {
    if (artistCoins.length > 0) {
      return {
        valid: false,
        error: 'Artist coins cannot be used for bulk wholesale orders.'
      };
    }
  }
  
  // Rule 3: Platform coins limited by platform margin
  const totalPlatformCoins = platformCoins.reduce((sum, c) => sum + c.amount, 0);
  const platformMargin = order.baseCost - order.productionCost; // e.g., €15 - €10 = €5
  
  if (totalPlatformCoins > platformMargin) {
    return {
      valid: false,
      error: `Maximum ${platformMargin} Platform Coins can be used on this order.`
    };
  }
  
  // Rule 4: Artist coins limited by artist margin
  const totalArtistCoins = artistCoins.reduce((sum, c) => sum + c.amount, 0);
  const artistMargin = order.totalPrice - order.baseCost; // e.g., €30 - €15 = €15
  
  if (totalArtistCoins > artistMargin) {
    return {
      valid: false,
      error: `Maximum ${artistMargin} ${order.artistName}'s Coins can be used on this order.`
    };
  }
  
  // Rule 5: Total discount max 50% of order value
  const totalDiscount = totalPlatformCoins + totalArtistCoins;
  if (totalDiscount > order.totalPrice * 0.5) {
    return {
      valid: false,
      error: 'Maximum 50% discount with coins.'
    };
  }
  
  return { valid: true };
}
```
