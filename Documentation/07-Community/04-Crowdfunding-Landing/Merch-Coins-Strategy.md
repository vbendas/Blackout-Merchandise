# Merch Coins: Comprehensive Marketing Strategy

## Executive Summary

**Merch Coins** is a zero-cost marketing amplification system that transforms artists into your viral growth engine. Artists receive free monthly coin allocations (1 coin = €1 discount) to distribute via social media campaigns, with all discounts coming exclusively from their profit margins. This creates authentic, artist-driven customer acquisition at zero cost to the platform.

**Key Metrics:**
- **Platform Cost:** €0 (discounts from artist margin)
- **Expected Social Reach:** 50-100 impressions per coin distributed
- **Redemption Rate Target:** 40% of distributed coins
- **Customer Acquisition Cost:** €0 via organic artist campaigns
- **Artist ROI:** 200-400% return on coin distribution efforts

## System Overview

### Core Concept

Merch Coins are **platform-only promotional credits** that artists use as a marketing tool to grow their fanbase and drive sales. The system operates on three fundamental principles:

1. **Artist-Funded:** All coin discounts come from artist profit margins
2. **Zero Platform Cost:** Platform never absorbs coin discounts
3. **Social Amplification:** Artists leverage social media reach organically

### How It Works

```
Monthly Cycle:
┌─────────────────────────────────────────────────┐
│ 1st of Month: Artist receives coins             │
│    - Free tier: 100 coins                       │
│    - Pro tier: 500 coins                        │
│    - Studio tier: 1,000 coins                   │
└─────────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────────┐
│ Artist runs social campaign                     │
│    "RT this + tag 3 friends = 5 Merch Coins!"   │
│    Distributes coins to winners                 │
└─────────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────────┐
│ Winners redeem coins at checkout                │
│    Customer: Saves €5                           │
│    Artist: Loses €5 from their margin           │
│    Platform: Production costs still covered     │
└─────────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────────┐
│ Results:                                        │
│    - Artist gains followers + engagement        │
│    - Platform gains new customers               │
│    - Everyone wins (except spam/bots)           │
└─────────────────────────────────────────────────┘
```

### Key Features

**For Artists:**
- Free monthly allocation based on subscription tier
- Full control over distribution (who, how many, when)
- ROI tracking dashboard
- Performance bonuses for milestones
- 6-month expiry encourages active use

**For Customers:**
- Receive coins via social media or direct from artists
- 1 coin = €1 off at checkout
- Works on any artist's store
- Expiry notifications create urgency

**For Platform:**
- Zero cost (discounts from artist margin)
- Organic customer acquisition
- Artist retention (coins = sunk cost if they leave)
- Viral social reach
- Built into subscription tiers (monetization)

## Economic Model

### Coin Allocations by Tier

| Tier | Monthly Cost | Monthly Coins | Effective Marketing Budget | Cost per Coin |
|------|--------------|---------------|----------------------------|---------------|
| **Free** | €0 | 100 | €100 discount power | €0 |
| **Pro** | $20 | 500 | €500 discount power | $0.04 |
| **Studio** | $50 | 1,000 | €1,000 discount power | $0.05 |

### Transaction Economics

**Example Order with Coins:**

```
Product Price: €25
Artist Margin: €10 (40%)
Platform Cost: €15 (production + base margin)

Customer uses 5 Merch Coins:
├─ Customer Pays: €20 (€25 - €5)
├─ Artist Gets: €5 (€10 margin - €5 coin discount)
└─ Platform Gets: €15 (unchanged)

Result:
✅ Platform: Full production cost covered + base margin
✅ Customer: €5 saved
✅ Artist: €5 margin remaining + marketing ROI
```

### Guardrails & Limits

**To Prevent Abuse:**

1. **Maximum Discount:** 50% of order value
   ```
    €30 order → Max 15 coins usable (€15 discount)
    €100 order → Max 50 coins usable (€50 discount)
    ```

2. **Minimum Order Value:** €10
   ```
    Prevents: Cheap item abuse (€5 item with 5 coins = free)
    Ensures: Meaningful purchases only
    ```

3. **Artist Margin Cap:**
   ```
    If artist margin = €8 on this product
    Customer can only use max 8 coins
    Prevents: Platform from absorbing discount
    ```

4. **Expiry:** 6 months rolling
   ```
    Coins received Feb 1 → Expire Aug 1
    Creates urgency without feeling unfair
    ```

5. **No Stacking:**
   ```
    Cannot combine: Merch Coins + Platform Promotion
    Customer chooses best discount
    ```

### Platform Promotions (Separate System)

**These are YOUR marketing costs, not artist-funded:**

| Promotion Type | Example | Who Absorbs | Purpose |
|----------------|---------|-------------|---------|
| New Customer | "€10 off first order" | Platform | Acquisition |
| Seasonal | "Black Friday: Buy 3 Pay 2" | Platform | Volume sales |
| Cart Abandon | "Come back for €5 off" | Platform | Recovery |
| AOV Boost | "Free shipping over €50" | Platform | Increase basket |
| Bundle | "Hoodie + Tee, save 15%" | Platform | Multi-item |

**Key Difference:**
- **Merch Coins:** Artist-driven, artist-funded, organic social reach
- **Platform Promos:** Platform-driven, platform-funded, direct acquisition

## Technical Implementation

### Database Schema

```sql
-- Coin wallets (per customer)
CREATE TABLE coin_wallets (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  customer_id UUID REFERENCES user_profiles(id),
  coin_type TEXT CHECK (coin_type IN ('platform', 'artist_branded')),
  balance INTEGER DEFAULT 0,
  expiry_date DATE, -- Coins expire 6 months after receipt
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Coin transactions (audit trail)
CREATE TABLE coin_transactions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  wallet_id UUID REFERENCES coin_wallets(id),
  campaign_id UUID, -- Which campaign issued these coins
  transaction_type TEXT CHECK (transaction_type IN ('credit', 'debit', 'expiry')),
  amount INTEGER NOT NULL,
  balance_after INTEGER NOT NULL,
  reference_id TEXT, -- Campaign ID, order ID, etc.
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Campaign tracking (for artists)
CREATE TABLE coin_campaigns (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  artist_id UUID REFERENCES user_profiles(id),
  name TEXT NOT NULL,
  campaign_type TEXT CHECK (campaign_type IN ('giveaway', 'engagement', 'milestone')),
  coins_issued INTEGER NOT NULL,
  coins_redeemed INTEGER DEFAULT 0,
  estimated_reach INTEGER, -- Social impressions
  estimated_conversions INTEGER, -- Expected new customers
  actual_conversions INTEGER, -- Measured new customers
  status TEXT CHECK (status IN ('active', 'completed', 'paused')),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  completed_at TIMESTAMPTZ
);

CREATE INDEX idx_coin_wallets_customer ON coin_wallets(customer_id);
CREATE INDEX idx_coin_transactions_wallet ON coin_transactions(wallet_id);
CREATE INDEX idx_coin_campaigns_artist ON coin_campaigns(artist_id);
```

### Campaign Effectiveness Tracking

```sql
-- Campaign performance dashboard
SELECT
  c.name as campaign_name,
  c.coins_issued,
  c.coins_redeemed,
  ROUND((c.coins_redeemed::numeric / c.coins_issued::numeric) * 100, 2) as redemption_rate,
  c.estimated_reach,
  c.actual_conversions,
  ROUND((c.actual_conversions::numeric / c.coins_issued::numeric) * 50, 2) as acquisition_cost_eur_per_coin,
  ROUND((c.actual_conversions::numeric * 35), 2) as revenue_generated_eur
FROM coin_campaigns c
WHERE c.artist_id = current_artist_id
ORDER BY c.created_at DESC;
```

## Risk Management

### Potential Issues & Mitigation

| Risk | Likelihood | Impact | Mitigation |
|--------|-------------|---------|-------------|
| **Artist doesn't use coins** | High | Medium | 6-month expiry creates urgency, reminders before expiry |
| **Coin farming/bots** | Medium | High | Rate limiting, account age requirements, payment verification |
| **Artists give all coins away** | Medium | Low | Artist margin cap (can only give away % of their margin) |
| **Coins devalue perceived value** | Low | Low | Clear communication: "1 coin = €1 real money value" |
| **Platform promo conflicts** | Low | Low | Clear separation, customers choose best discount |

### Fraud Detection

**Suspicious Patterns:**
- Multiple accounts from same IP claiming coins
- Coins redeemed but orders cancelled immediately
- High redemption rate (>80%) on specific campaigns

**Automated Actions:**
- Flag accounts for manual review
- Suspend coin grants during investigation
- Revoke coins from confirmed fraudsters
